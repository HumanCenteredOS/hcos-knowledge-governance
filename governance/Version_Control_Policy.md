# HCOS™ Version Control Policy

## Purpose

This policy establishes expectations for preserving change history and maintaining authoritative versions of HCOS artifacts.

## Requirements

- Maintain the authoritative source in a designated repository.
- Avoid unmanaged duplicate copies.
- Use descriptive commits that explain meaningful change.
- Use branches for substantive development when practical.
- Align document versions with changelog and release records.
- Preserve superseded versions when needed for traceability.

## Branch Naming Examples

```text
feature/knowledge-lifecycle
revision/hcos-i-003-v1-1
fix/classification-terminology
```

## Authoritative Copy

Cross-repository references should link to the authoritative source rather than duplicating content. Local copies must clearly identify synchronization responsibility.
