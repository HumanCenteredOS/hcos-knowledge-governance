# HCOS™ Repository Health Assessment

## Purpose

This assessment evaluates whether an HCOS repository remains navigable, maintainable, current, and aligned with ecosystem governance.

## Health Domains

- purpose and scope clarity
- README accuracy
- link integrity
- consistent metadata
- version and changelog alignment
- orphaned or duplicate documents
- stewardship ownership
- unresolved issues
- accessibility and usability
- archival and deprecation hygiene

## Rating

Use a simple status such as Healthy, Watch, At Risk, or Needs Intervention, supported by evidence and corrective actions.
