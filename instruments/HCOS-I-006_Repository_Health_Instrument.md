# HCOS™ Repository Health Instrument

## Purpose

Assess whether an HCOS repository remains coherent, navigable, current, and maintainable.

## Assessment Domains

- purpose and scope
- architecture alignment
- README and navigation
- metadata consistency
- link integrity
- version and changelog alignment
- duplicate or orphaned files
- ownership and review cadence
- issue and roadmap hygiene
- accessibility
- deprecation and archival practices

## Rating

For each domain assign:

- Healthy
- Watch
- At Risk
- Needs Intervention

## Output

- Overall status
- Strengths
- Risks
- Broken relationships or dependencies
- Priority corrective actions
- Responsible steward
- Target review date
