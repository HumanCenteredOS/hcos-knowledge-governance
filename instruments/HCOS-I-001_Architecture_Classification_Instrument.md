# HCOS™ Architecture Classification Instrument

## Purpose

Determine where new work belongs within the HCOS ecosystem and identify its relationships, maturity, and repository placement.

## Instructions

Review the proposed work and answer:

1. What is its primary purpose?
2. What problem does it address?
3. Is it primarily a belief, domain, expectation, process, tool, evidence source, interpretation, educational resource, governance rule, or stewardship activity?
4. Does an existing HCOS artifact already serve this purpose?
5. What evidence maturity does it represent?
6. Which documents does it depend on or affect?

## Classification Options

- Foundation
- Discipline
- Standard
- Method
- Instrument
- Research
- Insight
- Learning Resource
- Example
- Governance
- Stewardship

## Output

- Recommended primary classification
- Secondary relationships
- Evidence maturity
- Recommended repository and path
- Dependencies
- Duplication or conflict risks
- Governance review level
- Stewardship owner or next review need

## Guardrail

Do not elevate an artifact merely because it is compelling. Classification should reflect function and maturity.
