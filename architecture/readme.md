# architecture/

The `architecture/` directory contains the highest-level documents explaining how the HCOS™ ecosystem and its knowledge structures fit together.

## Documents

- `HCOS_Ecosystem_Architecture.md` — Authoritative ecosystem map. Add the approved document at this path.
- `HCOS_Knowledge_Governance_Framework.md` — Integrates knowledge architecture, governance, stewardship, and evidence.
- `HCOS_Knowledge_Architecture.md` — Defines HCOS knowledge categories and relationships.
- `HCOS_Knowledge_Lifecycle.md` — Describes movement from evidence to maintained knowledge.
- `HCOS_Evidence_Maturity_Model.md` — Defines evidence maturity levels.
- `HCOS_Architecture_Principles.md` — Establishes qualities expected of the architecture itself.

These documents are architectural rather than operational. Operational rules belong in `governance/` or `stewardship/`.
